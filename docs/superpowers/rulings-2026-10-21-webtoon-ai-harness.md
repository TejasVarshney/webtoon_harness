# Rulings made during implementation — Webtoon AI Harness

Every decision the implementation controller made on the user's behalf while executing `docs/superpowers/plans/2026-10-21-webtoon-ai-harness.md` (plus the final-review fix wave and the local-models follow-up), in the order made. Each reads: what was decided — why — what it costs if wrong. Rework any you disagree with.

- Ruling P1: Task 1 skips `git init` (repo + branch feat/webtoon-harness created in setup; implementer commits on that branch) — setup needed git for the SDD workspace — cost if wrong: none.
- Ruling P2: Task 1 adds `.gitattributes` with `* text=auto eol=lf` (and commits it) — exact-string tests need LF on a machine with autocrlf=true — cost if wrong: Windows tools see LF files (harmless for this stack).
- Ruling P3: Vitest `renderer` project includes `src/renderer/**/*.test.{ts,tsx}` (not only .tsx) — T6 api.test.ts is .ts — cost if wrong: none.
- Ruling P4: JSONL appends (appendJsonl) are exempt from writeFileAtomic but still run inside `ctx.mutex.run(absPath)`; readJsonl's skip-truncated-last-line is the crash guard — atomic rewrite of an append log is wasteful and the plan's own T3/T5 design relies on append — cost if wrong: one truncated trailing record per crash, already tolerated.
- Ruling P5: services.ts ↔ agent modules reference each other only via `import type` where a runtime cycle would otherwise form — keeps bundling sane — cost if wrong: none.
- Ruling P6: In createServices, construct CharacterService with a lazy `usage` delegate that forwards to `panels` once PanelService exists (T15 uses a `[]` stub until T18 wires the delegate) — breaks the construction cycle — cost if wrong: none.
- Ruling P7: Every version label (`vN` in tools, `version: v<n> of <m>` in panel_context, the UI switcher) counts READY versions only: N = 1-based index of the version among ready versions, M = ready count; non-ready versions report their status instead of a label — one consistent user-visible numbering; T21 and T22 tests agree with it — cost if wrong: cosmetic numbering.
- Ruling T1a: keep `vitest.config.mts` (not .ts) — Vite 8 warns on .ts config in a non-"type" package; only Task 1 names the file — cost if wrong: rename only.
- Ruling T1b: electron-vite 6 `build.externalizeDeps: false` for preload replaces externalizeDepsPlugin — follows installed version — cost if wrong: none.
- Ruling T1c: react-resizable-panels 4 API (Group/Panel/Separator, % strings) + ResizeObserver stub + afterEach(cleanup) in setup; tests import it/expect from vitest (no globals) — cost if wrong: none.
- Ruling T1d: subagent commits carry their own accurate model in Co-Authored-By (context.md updated) — accurate attribution — cost if wrong: trailer wording only.
- Ruling T1e: package.json private/UNLICENSED/productName/version 0.1.0 accepted — private desktop app; license is the user's to change — cost if wrong: user edits one field.
- Ruling T2a: fields §6 lists without a default stay required even when nullable (stateSnapshot, PanelVersion.error/imagePath/check, ToolResult.images, EndpointConfig.options, Panel.dialogue, Character.variations); services must always set them — matches §6 literally — cost if wrong: callers add explicit nulls/[]s.
- Ruling T2b: input/patch schemas (PanelDraft/PanelPatch/CharacterInput/CharacterPatch/VariationInput) carry no defaults (zod 4 .partial() would fire defaults and reset fields on patch) — correct patch semantics — cost if wrong: none.

- Ruling T3c: appendJsonl prepends "\n" when the file's last byte isn't a newline — protects the first record after a crash (Review Focus 1) — cost if wrong: none.
